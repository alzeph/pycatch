# Politique de sécurité

## Versions supportées

`pycatch` (distribué sur PyPI sous le nom `pycatch-safe`) est en pré-version
`1.0.0rc1` : seule la dernière version publiée reçoit des correctifs de
sécurité.

| Version    | Supportée |
| ---------- | --------- |
| 1.0.0rcN   | ✅        |
| < 1.0.0rc1 | ❌        |

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir d'issue publique pour une faille de sécurité.

Privilégiez le signalement privé via
[GitHub Security Advisories](https://github.com/alzeph/pycatch/security/advisories/new)
sur ce dépôt. À défaut, contactez l'auteur directement à
hervecedricyouan@gmail.com.

Merci d'inclure :

- une description du problème et de son impact potentiel ;
- les étapes pour le reproduire ;
- la version de `pycatch` concernée.

Nous accusons réception sous 72h et visons un correctif ou une réponse
motivée sous 30 jours selon la gravité.
